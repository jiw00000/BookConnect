REQ-01 · 회원 관리 & 재학생 인증
대학교 이메일 기반 신뢰 인증 시스템
📧
이메일 도메인 검증
가입 시 @ks.ac.kr (경성대) 또는 .ac.kr 도메인 자동 검증으로 재학생 신분 확인
👤
역할 기반 접근 제어
가입 후 역할(Role) 자동 부여
student admin — 각 역할별 페이지 접근 권한 분리
🔑
JWT 기반 보안 인증
로그인 후 JWT 토큰 발급, 모든 API 요청 시 서버 측 토큰 검증으로 비인가 접근 차단
SIGN UP FLOW
1️⃣
이메일 입력
.ac.kr 도메인 유효성 실시간 검사
2️⃣
개인정보 입력
학번·이름·비밀번호 유효성 검사
3️⃣
역할 부여
student / admin 자동 분류 및 DB 저장
4️⃣
로그인 & JWT 발급
세션 관리 및 보호된 라우트 접근

REQ-03 · 대시보드 & 내 서재
학습 현황을 한눈에 파악하는 스마트 서재 관리
📅
구독 D-Day 시각화
현재 구독 플랜(예: Standard)과 학기 종료일까지 남은 일수를 실시간으로 계산하여 대시보드 상단에 표시
📈
도서별 진도율 시각화
현재 열람 중인 도서마다 진도율(%)을 프로그레스 바 UI로 표시. 마지막 읽은 페이지 위치 저장
☁️
클라우드 동기화
진도율 및 스마트 필기 데이터를 서버에 자동 저장. 다른 기기에서 접속해도 이어보기 즉시 가능
06 / 09
REQ-04 · 전공 e서적 통합 탐색
원하는 전공 서적을 빠르게 찾고 내 서재에 추가
🔍
통합 검색 필터
제목 · 저자 · 카테고리 3가지 기준으로 동시 필터링, 결과 정렬(최신순/인기순) 지원
📋
도서 상세 페이지
표지·저자·출판사·목차 미리보기 제공, 구독 플랜 내 남은 열람 가능 권수를 실시간 표시
➕
내 서재 추가 로직
버튼 클릭으로 즉시 내 서재에 추가, 권한 초과 시 업그레이드 안내 팝업 자동 표시

REQ-06 · DRM 보안 & 저작권 보호
뷰어 진입 시 자동 작동하는 3중 보안 시스템
🚫
우클릭 & 복사 차단
뷰어 영역 내 마우스 우클릭 비활성화
Ctrl+C / Ctrl+A 키보드 단축키 이벤트 차단
시스템 클립보드 복사 원천 차단
📸
화면 캡처 & 녹화 방지
Print Screen · Win+Shift+S 단축키 이벤트 감지 및 차단
화면 녹화 프로그램 작동 감지 시 뷰어 콘텐츠 블랙아웃 처리
🔲
포커스 아웃 블랙아웃
브라우저 탭 전환 또는 창 포커스 해제 시
뷰어 콘텐츠 자동 블랙아웃 (화면 완전 가림)
재포커스 시 인증 후 복원
🔖
사용자 식별 워터마크
뷰어 배경에 사용자 이메일 + 학번 사선 텍스트를 CSS 동적 생성 렌더링
불법 유출 시 원본 사용자 추적 가능
🛡️
모든 보안 기능은 e북 뷰어(BookViewer.jsx) 진입 시 자동 활성화되며, 뷰어 종료 시 자동 해제됩니다.
